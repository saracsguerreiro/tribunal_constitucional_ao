# Tribunal Constitucional — Plataforma de Gestão Documental e Processos Judiciais

Protótipo interativo (não funcional em produção — dados fictícios) da plataforma de gestão documental
e processos judiciais para o Tribunal Constitucional, com base no regulamento de construção do protótipo.

## Ver o protótipo

Abra `index.html` num browser (precisa de ligação à internet, para carregar tipos de letra e bibliotecas).

Também pode ativar o **GitHub Pages** deste repositório (Settings → Pages → Deploy from branch → `main` / `/root`)
para o ver diretamente num link público.

## Entrar

No ecrã de login pode usar qualquer e-mail e uma password com 8 ou mais caracteres — não há campos obrigatórios,
é possível avançar em todos os formulários mesmo sem os preencher.
